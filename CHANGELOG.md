# Changelog

## v0.0.4b - 2026-05-26

### Added

- Added the EventDeckSystem autoload and expanded travel/event deck state support.
- Added Splice enemy body-part data, scene, and script.
- Added dedicated scripts for Collapsed Service Atrium, Dead Food Court Bloom, and Water Reclamation Cistern.
- Added planning docs for Cooters job destinations, Faded Atrium buildout, and quest-location buildout.

### Changed

- Expanded Cooters job destination handling and route/event logic across the Sub-Sub-Basement travel loop.
- Updated Faded Atrium, Pipe Utility Tunnels, and district flow scripts for the new destination/event structure.

## v0.0.4 - 2026-05-25

### Added

- Added README project overview and release/build orientation.
- Added Cooters job board and travel loop support.
- Added Pipe Utility Tunnels plus new job-location scenes for lower-city errands.
- Added additional Sub-Sub-Basement plan/reference documents, including terrain, survival-site, NPC writing style, and Cooters route expansion references.
- Added expanded job, world flag, and persistence coverage in `GameState`.
- Added more district NPC/support logic for the current Leak Street slice.

### Changed

- Repositioned the game in the master design document as a tactical survival FPS with immersive RPG systems.
- Updated protagonist canon: Spooky Ghost is now the main character, returned as a later-timeline ghost in an android body.
- Updated Linda canon: Linda is alive, CEO of Gatebox Corporation, formerly close to Spooky Ghost, and personally motivated to capture him once she recognizes his return.
- Updated Gatebox pressure design around attention/heat, where drawing attention escalates the corporate hunt.
- Updated Sub-Sub-Basement design around Leak Street, Cooters jobs, travel routes, Wan Notes, and the Dreaming Generator's wasted-potential economy.
- Reworked Sub-Sub-Basement visual dressing with clearer floor/wall tiling, larger storefront facades, cropped signage, generator-linked lights, and tighter route placement.
- Updated the Leak Street signage atlas art.
- Tuned player viewpoint, catwalk traversal support, NPC facing behavior, and several scene scripts for the expanded district loop.

### Fixed

- Fixed several UI and interaction flow issues around job/travel panels and inventory summaries.
- Fixed Suitors interaction stability after repeated use.
- Fixed multiple stretched/overlapping Leak Street texture and facade placement problems.
- Fixed rain mutant containment clarity and related body-part/completion behavior.
- Fixed player/catwalk collision height issues that made elevated traversal snag on visual geometry.

### Notes

- `v0.0.4` is a content and systems slice release. It is still an early prototype; several visual tuning controls and placeholder encounter elements remain intentionally present for iteration.
