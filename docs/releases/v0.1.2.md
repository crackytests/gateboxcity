# Gatebox City — v0.1.2 Patch Notes

Adds an enemy compendium to the GhostTerm and tidies up the cyberware tab.

---

## Enemy Compendium (GhostTerm CODEX tab)

A new **CODEX** tab in the GhostTerm catalogues the enemies you fight, unlocking more detail the
more times you kill each one.

- **Roster + progress:** every rank-and-file enemy has an entry. Ones you haven't killed yet show
  as `??? — UNIDENTIFIED`, so you can see how much there is to discover.
- **Progressive reveal by kill count:**
  - 1st kill — the enemy is named and its front sprite is logged.
  - ~3 kills — its **weak points** and what breaking each does.
  - ~6 kills — the **salvage** it can drop (item names).
  - ~10 kills — the **exact drop percentages** (cyberware, ruined parts, specials).
  - A "kills to next reveal" line tells you how close you are to the next unlock.
- Kills are tracked per species and persist across save/load, including the faction variants
  (Gatebox Sentinel, Foundation Enforcer, Tithe Servitor, Soul Harvester Drone) and the Rain Mutant
  (logged when you contain it).

## Cyberware Tab Tidy

- The **WARE tab is now hidden** on your own GhostTerm — cyberware is only handled at Velvet Coil's
  surgical table, so the tab only appears there during cybersurgery. Tab navigation (`Q`/`E` cycle)
  skips it when hidden; press `7` for the new CODEX tab.

## Other

- **Sunday** (Suitors) now uses a directional sprite like the hub residents.
- More robust audio loading (falls back to loading `.ogg` streams directly when needed).
